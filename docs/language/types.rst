.. _types:

类型系统与 Java 映射
====================

本节定义结绳的类型表示、名称解析、数组/泛型/可空后缀、隐式转换，以及源类型到 Java 类型的映射。实现锚点：

- ``src/targets/java/java_type_mapper.cpp``\ ：``JavaTypeMapper::MapType``\ 、``BaseTypeName``
- ``src/ir/symbols.cpp``\ ：``SymbolTable::Resolve``
- ``src/targets/java/java_support.cpp``\ ：``InitializerExpression``\ 、``FindImplicitCast``
- ``src/targets/java/java_generics.cpp``\ ：泛型特化与 ``MapGenericAwareType``
- ``src/targets/java/java_lint.cpp``\ ：``InferTypeName``\ 、``TypesCompatible``\ 、``IsUnsafeCast``
- ``stdlibs/安卓基本库/源代码/Java/JVM_基本类型.t``\ ：核心别名声明

.. contents:: 目录
   :local:
   :depth: 2

类型表示
--------------------------------------------------------------------------------

类型不是结构化的 ``Type``\ 对象，而是 **原始字符串**\ 。例如：

- ``整数``
- ``文本``
- ``集合<文本>``
- ``整数[3]``
- ``整数[2][2]``
- ``集合<整数[]>?``
- ``结绳.安卓.窗口``

parser 的 ``ParseTypeName``\ 只做词法拼接：

- 基名可以是点分标识符；
- ``<...>``\ 内的 Token 直接拼接，嵌套 ``<``/``>``\ 计数，空白被去除；
- ``[...]``\ 内的容量表达式直接拼接，只跟踪圆括号嵌套；
- 末尾的 ``?``\ 可重复，全部保留在类型字符串中；
- 缺失类型允许（空字符串）。

后续阶段：

- ``BaseTypeName``\ 剥离 ``<...>``\ 、从 ``[``\ 或 ``?``\ 处截断，用于符号解析。
- ``ParseTypeShape``\ 拆分 ``base``\ 、``dimensions``\ 、``capacities``\ ，用于数组初始化。
- ``JavaTypeMapper::MapType``\ 递归映射泛型实参并追加数组 ``[]``\ 。
- 符号解析在查找时剥离泛型/数组/``?``\ 。

类型分类
--------------------------------------------------------------------------------

.. list-table:: 类型分类
   :header-rows: 1
   :widths: 20 80
   :name: table-type-categories

   * - 类别
     - 说明
   * - 值类型
     - 由标准库 ``@指代类``\ 映射到 Java 原始类型的源类型，如 ``整数``\ 、``逻辑型``\ 、``字符``\ 。
   * - 引用/别名类型
     - 由 ``@指代类``\ 映射到外部 Java 类的源类型，如 ``文本``\ 、``集合<T>``\ 、``安卓窗口``\ 。
   * - 用户类
     - 由 ``类``\ 声明的类型，输出为生成的 Java 类；可单继承。
   * - 数组
     - ``T[]``\ 或多维 ``T[n][m]``\ ；不是标准库类，映射为 Java 数组。
   * - 泛型类
     - 用户泛型类或外部泛型别名；用户泛型生成空壳 + 特化，外部泛型保留 Java 泛型实参。
   * - 可空后缀
     - ``T?``\ ；不改变 Java 类型，只抑制部分自动初始化。
   * - 伪类型
     - ``任意类型``\ 、``任何类型``\ 、``类型``\ 、``变体型``\ ；只在注解符号索引/部分 lint 中识别，不是真实标准库类型，也不映射为 ``Object``\ 。

类型名称解析
--------------------------------------------------------------------------------

``SymbolTable::Resolve(type_name, context_class)``\ 的顺序：

1. 用 ``BaseTypeName``\ 去掉泛型/数组/``?``\ ；
2. 尝试精确全名（含包名）查找；
3. 尝试与上下文类同包的简单名；
4. 尝试全局唯一简单名索引；若同一简单名在多个包中出现，索引被置空，查找失败；
5. 失败返回 ``nullptr``\ 。

后果：

- 成员、参数、局部变量与泛型实参中的未解析类型会报 ``semantic.type.unresolved``\ ；分析阶段有错误时不会写出产物。
- 同时加载两套标准库导致简单名歧义时，简单名索引会失效；典型例子是 ``集合``\ 同时存在于 ``结绳.JVM``\ 与 ``结绳.基本``\ 。按目标只加载一套标准库。
- ``@全局基础类``\ 只影响全局基础类登记，不会自动注入基类；重复声明会报错。

数组
--------------------------------------------------------------------------------

数组是类型语法的一部分，不是标准库类。

.. list-table:: 数组映射与初始化
   :header-rows: 1
   :widths: 24 30 46
   :name: table-arrays

   * - 源类型
     - Java 类型
     - 初始化/说明
   * - ``整数[]``
     - ``int[]``
     - 普通数组类型。
   * - ``文本[]``
     - ``String[]``
     - 普通数组类型。
   * - ``对象[]``
     - ``Object[]``
     - 普通数组类型。
   * - ``整数[3]``
     - ``int[]``
     - 字段/局部声明点生成 ``= new int[3]``\ ；``MapType``\ 本身只输出 ``int[]``\ 。
   * - ``整数[2][2]``
     - ``int[][]``
     - 生成 ``new int[2][2]``\ ；每层方括号逐个追加。
   * - ``整数[][] = {{1,2},{3,4}}``
     - ``int[][]``
     - 数组字面量在初始化器上下文发射为 ``new int[][]{{1, 2}, {3, 4}}``\ 。
   * - ``整数[]``\ 的 ``长度``
     - ``int``
     - 数组字段访问 ``数组.长度`` 发射为 ``数组.length``\ ；直接使用 Java 数组长度。

数组规则：

- ``ParseTypeShape``\ 拆分 base、维度与容量；容量可以表达式，emitter 直接拼入 ``new T[cap]``\ 。
- ``MapType``\ 对每个 ``[``\ 追加一个 ``[]``\ ；容量被丢弃。
- 数组是 Java 协变的；源类型检查不会阻止运行期 ``ArrayStoreException``\ 。
- 数组字面量在初始化器上下文（字段/局部声明、返回/参数转换等由 ``InitializerExpression`` 处理的位置）包装为 ``new T[]{...}``\ ；其他位置按嵌套深度发射 ``new Object[]{...}``\ ，保持 Java 语法合法。

泛型
--------------------------------------------------------------------------------

声明：

.. code-block:: text

   类 盒子<元素类型 = 对象>
       变量 内容: 元素类型
   结束 类

使用：

.. code-block:: text

   变量 整数盒子: 盒子<整数>

规则：

- 类声明记录泛型参数名、默认值标记与默认类型文本。
- 使用处未写全实参时按默认值补齐；后续默认值可以引用前面的实参，例如 ``对<A, B = A>`` 在 ``对<文本>`` 中把 ``B`` 补成 ``文本``。
- lint 仍检查 arity/默认值覆盖（``semantic.generic.arity``\ ）；缺少无默认值参数会报错。
- 用户泛型类：
  - 生成空壳类 ``盒子.java``\ ：``public class 盒子 ... { }``\ （类级 ``@隐藏`` 时为包私有）；
  - 按实参生成特化类 ``盒子$整数.java``\ ；
  - 数组实参编码为 ``$Array``\ （每个 ``[``\ 一个）；
  - 嵌套泛型递归编码，例如 ``外盒<内盒<整数>>`` → ``外盒$内盒$整数``\ 。
- 外部泛型类（``@指代类``\ ）：
  - 不生成裸壳/特化文件；
  - 保留 Java 泛型实参，例如 ``集合<文本>`` → ``java.util.ArrayList<String>``\ ；
  - 成员发射为静态跳板，首参 ``__this_obj``\ 。
- 特化扩展有 500 轮上限（``kMaxGenericExpansionRounds``\ ），防止无限递归。
- 没有方法级泛型、泛型约束、通配符、型变标注。

可空后缀 ``?``
--------------------------------------------------------------------------------

``T?``\ 不是 Java 的可空类型：

- ``BaseTypeName``\ 在 ``?``\ 处截断，Java 类型不变；
- 不进行空安全检查，也没有 ``Optional``\ 包装；
- 只影响自动初始化：
  - 字段：抑制 ``new T()``\ 与 ``文本``\ 的自动 ``""``\ ；
  - 局部变量：抑制自动默认值（用户类 ``new T()``\ 、``文本``\ 的 ``""``\ 与原始类型零值）；
- ``空``\ 到原始类型会转成零值，到引用类型为 ``null``\ 。

隐式转换与赋值兼容
--------------------------------------------------------------------------------

转换上下文：赋值、参数传递、返回值、字段/局部初始化、属性写。实现入口是 ``InitializerExpression``\ （``java_support.cpp``\ ）。

解析顺序：

1. **空值转换**\ ：``空`` → 原始类型零值（``0``\ 、``0L``\ 、``0.0F``\ 、``0.0``\ 、``false``\ 、``(byte) 0``\ 、``'\\0'``\ ）；引用类型 → ``null``\ 。
2. **数组字面量**\ ：目标维度 > 0 且值是 ``kArrayLiteral`` → ``new T[]{...}``\ （多维递归）。
3. **隐式 cast**\ ：从值的静态类型沿基类链查找 ``@隐式操作("cast")``\ 方法；找到则发射 ``value.method()``\ 。
4. **引用转型**\ ：值为标识符/字段访问，声明类型与值类型不同、不是向上转型、目标类没有 ``=``\ 运算符 → ``(Target)value``\ 。
5. **``=``\ 运算符构造转换**\ ：目标类链存在名为 ``=``\ 的方法且不是直接 ``new``/同类型 → ``Target.operator_assign(value)``\ 。
6. **原样发射**\ ：交给 Java 的赋值兼容/装箱/拓宽规则。

数值转换：

- Java 原生拓宽（``byte→short→int→long→float→double``\ 、``char→int``\ 等）由 Java 完成。
- 窄化需要显式 ``: 类型``\ 转换；lint 会用 ``PrimitiveRank``\ 与 ``IsUnsafeCast``\ 报 ``auto.type-cast``\ 警告。
- 装箱/拆箱由 Java 自动完成；源语言没有单独的装箱语法。
- 常量折叠按 32 位 ``int`` 回绕，匹配 Java ``int`` 溢出的语义；带 ``L`` 后缀的长整数表达式不参与这条整数折叠路径。

``@隐式操作("cast")``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

要求：

- 方法位于源类型或其基类链；
- 注解文本参数为 ``cast``\ （只支持这一种）；
- 方法无参数；
- 返回类型等于目标类型，或目标类型沿基类链能到达该返回类型。

发射：``value.<方法输出名>()``\ 。源码示例：

.. code-block:: text

   类 来源
       @隐式操作("cast")
       方法 转目标(): 目标
           返回 创建 目标
       结束 方法
   结束 类

``=``\ 运算符
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

要求（lint 检查）：

- 方法名为 ``=``\ ，或带 ``@运算符重载``\ ；
- 必须是 ``@静态``\ ；
- 返回当前类（按基名比较）。

发射：``Target.operator_assign(value)``\ 。若目标类型没有 ``=``\ 运算符、值是直接 ``new Target``\ 、或类型相同，则不插入转换。

类型推断
--------------------------------------------------------------------------------

没有一般性类型推断：

- 局部变量未写类型：发射为 ``Object``\ ；
- 参数/字段未写类型：发射为 ``Object``\ ；
- 方法未写返回类型：发射为 ``void``\ ；
- 缺少初始化器的局部变量按类型补默认值：原始类型零值、``文本 = ""``、其他引用类型 ``new T()``；``?`` 抑制默认创建，用户类受 ``@禁止创建对象`` 限制。

存在的局部推导：

- 发射期 ``StaticTypeNameOf``\ ：局部/参数/字段、字面量、字段访问、二元运算符重载返回类型等有限子集；用于运算符分派、属性/字段选择、``<=>``\ 临时变量类型。
- lint 期 ``InferTypeName``\ ：字面量、标识符、``本对象``\ 、字段、调用、``创建``\ 、转换、数组字面量（取最宽原始类型）、下标、括号、二元运算（比较/逻辑→逻辑型；``+``/``&``\ 含文本→文本；含小数→小数；含长整数→长整数；否则整数）。
- 遍历循环的元素类型从集合静态类型推导：数组取 base，泛型取第一个实参，否则 ``Object``\ 。

类型检查范围
--------------------------------------------------------------------------------

没有独立类型检查 IR；Java 后端在发射前运行 lint（``JavaEmitter::RunAnalysisLints``\ ）。覆盖：

- 基类禁止继承、循环继承；
- 类型/泛型 arity、成员/局部/泛型实参的未解析类型；
- 循环外 ``退出循环``/``跳过循环``\ ；
- 原始类型的 ``属于``\ 判断；
- 属性读/写参数与返回规则；
- ``[]``/``[]=``/``=``/``隐式操作``\ 规则；
- 调用实参数量与默认参数；
- 静态成员用对象访问警告；
- 非异步方法中的 ``等待``\ ；
- 算术/比较/赋值/交换/``[]=``\ 的类型不匹配；
- 未知符号、重复局部变量、遮蔽警告；
- 不可达语句、非全分支返回；
- 未使用局部变量。

注意：

- ``@废弃使用``\ 的类/成员在使用处产生 ``semantic.deprecated``\ 警告。
- 数组的 ``长度`` 属性会发射为 Java ``.length``。
- 外部 ``@指代类`` 类型的运算符重载通过静态跳板分派；例如 ``文本 ==`` 发射为 ``文本.operator_equal(...)``。
