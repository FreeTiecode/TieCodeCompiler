.. _semantics:

语义等价性规约
==============

本节定义源语言到 Java 的翻译关系、可观察等价的条件，并逐特性说明“源语言结构在目标语言中的预期行为”。脱糖的实现细节见 :doc:`desugaring`；类型与转换规则见 :doc:`types`。

.. contents:: 目录
   :local:
   :depth: 2

翻译关系与等价
--------------------------------------------------------------------------------

记 ``⟦s⟧``\ 为源结构 ``s``\ 经 FTC 发射后的 Java 文本/结构。记 ``≈``\ 为在 Java/JVM 语义下的可观察等价：对任意上下文，两个程序满足以下条件时视为等价：

1. **终止行为相同**\ ：都正常终止、都抛出同类异常，或都不终止。
2. **结果相同**\ ：返回值、字段/数组最终状态相同。
3. **副作用顺序与次数相同**\ ：方法调用、赋值、I/O、事件注册等按相同顺序发生相同次数。
4. **对象身份与别名关系相同**\ ：``==``\ 引用比较、共享引用、数组别名不被改变（除非源语义明确允许）。
5. **异常相同**\ ：异常类型、抛出点与传播路径一致。
6. **线程可观察行为相同**\ ：对异步代码，调度点、线程切换与恢复顺序满足源语言的协作式语义。

这不是对所有程序的无条件保证。下面每个特性给出的“等价条件”是 **充分条件**\ ；违反条件时，目标行为可能不同，正文会标注。

类型与转换判断
--------------------------------------------------------------------------------

基本判断：

.. math::

   \Gamma \vdash e : T
   \qquad
   \Gamma \vdash e : T \rightsquigarrow e' : U

前者表示表达式 ``e``\ 在环境 ``Γ``\ 下具有类型 ``T``\ ；后者表示 ``e``\ 被转换为类型 ``U``\ ，目标表达式为 ``e′``\ 。

子类型关系 ``T <: U``\ ：

- 用户类：沿 ``:``\ 基类链的单继承关系。
- ``@指代类``\ 外部类型：由 Java 自身的继承/可赋值关系决定。
- 数组：Java 数组协变（``T[] <: Object``\ 、``T[] <: Object[]``\ 等）；源语言不额外检查。
- 泛型：用户泛型通过特化消除；外部泛型遵循 Java 泛型不型变规则。
- 没有结构类型、交叉类型、联合类型、通配符或型变标注。

Java 目标语义
--------------------------------------------------------------------------------

以下行为由 Java/JVM 决定，源语言不另行定义；文档必须明确它们：

- ``整数``\ 是 32 位有符号 ``int``\ ，``长整数``\ 是 64 位有符号 ``long``\ ；未折叠的算术按 Java 规则溢出回绕。
- 整数除法向零截断；除数为零抛 ``ArithmeticException``\ ；``%``\ 为 Java 余数。
- ``小数``/``单精度小数``\ 是 IEEE 754；支持 ``NaN``/``Infinity``\ 结果（但没有字面量）。
- ``字符``\ 是 UTF-16 代码单元；``文本``\ 是 UTF-16 ``String``\ ；索引/长度以代码单元计。
- 对象 ``==``\ 是引用比较；``文本 ==``\ 会分派到标准库的 ``文本.operator_equal``\ （外部类型静态跳板）。
- ``且``/``&&``\ 与 ``或``/``||``\ 短路；``&``/``|``/``^``\ 不求值短路。
- ``文本 + null``\ 得到 ``"null"``\ ；字符串拼接遵循 Java ``String.valueOf``\ 行为。
- 数组越界抛 ``ArrayIndexOutOfBoundsException``\ ；``null``\ 解引用抛 ``NullPointerException``\ ；空 ``Integer``\ 拆箱为 ``int``\ 也抛 NPE。
- 目标语言没有受检异常语法；``code``\ 中的 Java 代码可以抛出受检异常，生成的 Java 方法不一定声明它。
- 方法默认是虚分派；``@静态``\ 变为静态方法；``@隐藏``\ 让类/成员省略 ``public``\ ；没有 ``private``/``protected``\ 源语法。
- ``常量``\ 生成 ``final``\ 字段；只有无副作用的字面量表达式体在同类使用处内联，其余使用字段引用，避免重复求值与对象身份变化。

逐特性说明
--------------------------------------------------------------------------------

编译单元、包、类
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``包名``\ 生成 ``package``\ ；``@输出名``\ 在 unit 级且值含 ``.``\ 时改写输出包。
- 类生成 ``public class``\ ；有基类时 ``extends``\ ；外部基类通过 ``@外部基础类``\ 或 ``@指代类``\ 影响。
- 单继承；没有接口、枚举、命名空间、模块。
- 类名/成员名按命名方案重写；``@输出名``\ 可覆盖类/成员名（类名必须是合法 Java 标识符）。
- 类级 ``code``\ 块原样插入类体（在普通成员之后）；类级 code 块不能带注解。

字段、常量与初始化
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 字段默认值策略见 :ref:`sugar-autoinit`。
- 局部变量也会补默认值：原始类型零值、``文本 = ""``\ 、``对象``/外部引用 ``new T()``\ 、用户类 ``new T()``\ ；``?``\ 抑制默认值。
- ``常量``\ 生成 ``final``\ ；同类常量且带表达式体时，使用处内联表达式。
- ``?``\ 抑制自动 ``new``\ 与 ``文本``\ 的 ``""``\ 。
- ``@禁止创建对象``\ 抑制自动 ``new``\ ；未初始化变量可能被 lint 报错。
- 组件字段可能由平台生成 ``onInit``/``onCreateComponent``\ 初始化，而不是简单 ``new``\ 。

方法、参数与默认参数
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 方法体：块体、``= expr``\ （仅当返回类型非空时发射 ``return expr;``\ ）、``= code``\ 、``= ...``\ （声明）。
- 参数默认值在调用点展开；无重载。
- 调用参数空洞使用默认值；无默认值补 ``null``\ 。
- ``@静态``\ 加 ``static``\ ；``@隐藏``\ 省略 ``public``\ ；``@前缀代码``/``@后缀代码``\ 插入原样文本。
- 返回语句使用 ``InitializerExpression``\ 做目标类型转换。

.. _sem-property:

属性
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``obj.p`` → ``obj.p()``\ ；``obj.p = v`` → ``obj.p(v)``\ 。
- 外部别名 → ``Owner.p(obj)``/ ``Owner.p(obj, v)``\ 。
- 属性读优先于同名字段。
- 裸标识符 ``p``\ 不重写；只有字段访问路径会查属性。
- 等价条件：属性访问器无额外副作用，或副作用与直接字段访问的预期一致；接收者表达式只求值一次。
- ``@属性需求``\ 会在事件订阅后调用 ``receiver.property(true)``\ 。

.. _sem-events:

事件
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``定义事件``\ 生成监听器接口、字段、分发方法、setter；无监听器时返回默认值。
- 事件块生成匿名监听器注册；处理器方法 ``obj$event``\ 。
- 自动订阅在组件的 ``创建完毕``\ 末尾；显式 ``订阅事件``\ 立即发射类内全部事件块。
- 等价条件：监听器注册时机、顺序、参数与返回值一致；事件块目标与类内声明一致。
- 限制：``订阅事件``\ 的目标表达式被忽略；同一方法内重复订阅会去重；``字符``/``字节``/``短整数``\ 使用零值默认返回。

条件与分支
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``如果``/``否则``\ 直接映射；条件按 Java 布尔求值。
- 常量条件折叠：真只保留 then，假只保留 else，并报 ``code.constant-if``\ ；这不改变可观察行为（条件无副作用时）。
- ``否则 <条件>``\ 是嵌套 ``if``\ ；``否则 如果``\ 递归解析。两种写法都只使用一个 ``结束 如果``。
- ``假如``\ 映射 ``switch``\ ；case 值必须是 Java 常量；emitter 自动插入 ``break``\ ，因此没有 fallthrough；``否则``\ 是 ``default``\ 。
- 等价条件：case 值唯一/常量、没有依赖 fallthrough 的源写法（源语言也没有 fallthrough 语法）。

.. _sem-loops:

循环
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

计次循环：

.. code-block:: java

   for (int t = begin; t < end; t += step) { ... }

- 结束值独占；``begin``\ 只求值一次；``end``\ 每轮求值，动态 ``step``\ 求值一次。
- 缺省 ``begin=0``\ 、``end=0``\ 、``step=1``\ 。
- 等价条件：常量步长按正/负选择 ``<``/``>``\ ；动态步长生成一次方向判断。

遍历循环：

.. code-block:: java

   for (E x : coll) { ... }

- ``coll``\ 只求值一次。
- 元素类型 ``E``\ 从声明类型推导；无法推导时为 ``Object``\ 。
- 对 ``Iterable``\ 使用迭代器协议；对数组由 ``javac``\ 生成索引遍历，但源层不暴露索引。
- 等价条件：``coll``\ 是数组或 ``Iterable``\ ；元素类型与实际元素兼容；不依赖第二循环变量。
- ``循环(map -> k, v)``\ 使用 ``entrySet()``\ 遍历，并通过 ``getKey()``/``getValue()``\ 绑定键值。

条件循环：``while (cond)``\ ；条件每轮求值。

跳转与返回
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``退出循环`` → ``break;``\ ；``跳过循环`` → ``continue;``\ 。
- ``返回`` → ``return``\ ；无返回值时为 ``return;``\ ；带值时做目标类型转换。
- lint 会检查循环外的 ``break``/``continue``\ 并报错，不会生成非法 Java。
- 异步方法中的 ``返回``\ 只能提前结束，不能带值。

表达式与字面量
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 字面量：数字、字符、字符串、长字符串、``真``/``假``/``空``\ 。
- 数字字面量：``1.5L``\ 被词法拒绝；``0xFFL``\ 是合法长整数；``1.``\ 是整数加符号点。
- 标识符：局部/参数/字段/全局类成员；类名在表达式中输出 ``类名.class``\ （``#expr``\ 内联时只用类名）。
- ``本对象`` → ``Class.this``\ ；``父对象`` → ``super``\ ；``空`` → ``null``\ 。
- 字段访问：属性读优先，否则字段；外部类型静态跳板。
- 调用：默认参数补全；``@嵌入式代码``\ 调用点内联；外部类型静态跳板。
- ``创建 T`` → ``new T()``\ ；组件类可能传 ``Outer.this``\ ；构造参数被拒绝。
- 数组访问：Java 数组或 ``operator_array_access``\ ；数组写或 ``operator_array_assign``\ 。
- 显式转换：``(T) value``\ 。
- ``属于``\ ：``value instanceof T``\ ；原始类型会报错。
- 赋值：属性写、下标写、普通赋值分别降级；右侧做转换。
- ``<=>``\ ：仅语句位置；普通左值临时变量交换；对象下标交换读取两侧后分别写回。
- 多表达式 ``(a,b)``\ ：调用实参中展开；初始化器中通过 ``=`` 运算符构造；其他位置非法。
- ``等待``\ ：异步状态机替换；``如果``\ /while 条件与 ``假如``\ 分支体中的等待支持，foreach 循环体支持；计次循环头部与 foreach 集合表达式中的等待不支持。

.. _sem-operators:

运算符
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 算术/位/比较/逻辑：Java 运算符；``且/或``\ 短路；``&|^``\ 不短路。
- 字符串 ``+``\ ：Java 字符串拼接；常量折叠可能提前求值。
- 用户类型二元运算符：若左类型找到同名方法 → ``left.operator_xxx(right)``\ ；外部类型发射 ``Owner.operator_xxx(left, right)``\ 。
- ``[]``/``[]=``\ ：用户下标器方法。
- ``=``\ ：静态 ``operator_assign``\ 。
- ``?``\ ：用户类型/外部类型可重载（外部方法名 ``operator_question``\ ）；原始类型会发射二元 ``?``\ ，通常不是合法 Java。
- ``==``/``!=``\ ：用户类型/外部类型可重载；任何类型都优先查重载，找不到才回退 Java 运算。
- ``<=>``\ ：不是普通运算符表达式；只在语句位置由 ``EmitSwap``\ 处理；``operator_swap``\ 名称存在但不分派。
- 等价条件：运算符重载的返回类型/副作用与源声明一致。

类型、泛型与可空
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 用户泛型：空壳 + 特化；每个使用到的实参生成 ``X$Arg``\ ；未生成的特化不会被自动补齐（扩展循环有上限）。
- 外部泛型：保留 Java 泛型，不做特化；外部类型成员是静态跳板。
- 泛型默认值：使用处未写全实参时按声明中的默认类型补齐；后续默认值可引用前面的实参。
- 可空 ``?``\ ：不改变 Java 类型，无空安全检查；只抑制自动初始化。
- 等价条件：每个使用的泛型实例都生成/映射成功；类型实参在 Java 中合法。
- 未解析的成员/局部/泛型实参类型会报 ``semantic.type.unresolved``\ ；不会静默生成非法 Java。

数组
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``T[]`` → ``T[]``\ ；``T[n]``\ 在声明点生成 ``new T[n]``\ ；多维逐层。
- 数组字面量在初始化器上下文包装为 ``new T[]{...}``\ ；其他位置按嵌套深度发射 ``new Object[]{...}``\ 。
- 数组协变、越界、``ArrayStoreException``\ 遵循 Java。
- ``数组.长度`` 发射为 Java ``数组.length``\ 。

code 与 ``#``\ 引用
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``code``/``@code``\ 是宿主逃逸：不解析、不类型检查、不做语义保证。
- ``#``\ 替换是文本级的；引号感知；未解析内容保持原文。
- 等价条件：替换后的 Java 文本合法、名称解析正确、没有重复求值/副作用变化。
- ``@end``\ 只在行首、且不在字符串/字符/注释中终止；``obj.code``\ 是字段访问；未闭合的块注释/长字符串会报错。
- 长字符串 ``[[...]]``\ 不是普通 Java 字符串表达式，主要用于元数据/清单片段。

.. _sem-async:

异步
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``@异步方法``\ 将方法体拆成上下文类 + 状态机方法 + 包装方法。
- 等待前在全局调度器；等待后在主线程；``独立线程``\ 使用独立单线程调度器。
- 等价条件：等待点、线程切换、恢复顺序与协作式语义一致；等待后的语句在主线程执行。
- 支持：``如果``\ 、``假如``\ 、计次循环、while、foreach（含循环体内等待）、``退出循环``\ 、``跳过循环``\ 、``返回``\ 、局部变量、语句/变量初始化中的等待、``如果``\ 条件与 while 条件中的等待。
- 受限：计次循环头部（begin/end/step）中的等待不支持；foreach 的集合表达式本身不能等待；异步方法不能有返回类型；``code``\ 初始化局部变量受限。
- 这不是“阻塞调用”的等价物：它是协作式调度，调用方不应假设同步完成。

顶级语句
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 开启 ``--enable-toplevel-stmt``\ ：文件名 stem 合成类，顶层成员补 ``@强制输出``\ ，顶层语句进入 ``顶级语句``\ 方法；合成类带 ``@全局类``\ 与 ``@强制输出``\ 。
- 未开启：顶层语句报 ``源文件中只允许类声明``\ 。
- 等价条件：合成类的静态/实例上下文与入口调用方式匹配；顶层代码不依赖未生成的成员。

关键不变量
--------------------------------------------------------------------------------

以下不变量在正文声称“等价”时必须成立：

1. **求值顺序**\ ：Java 从左到右、参数从左到右；源语言的二元/调用/数组访问遵循同一顺序。
2. **短路**\ ：``且/或``\ 必须短路；不要用非短路位运算替换。
3. **集合只求值一次**\ ：遍历循环的集合表达式只求值一次。
4. **结束值独占**\ ：计次循环不包含结束值。
5. **属性接收者一次**\ ：属性读/写的接收者表达式不应被重复求值。
6. **事件注册顺序**\ ：类内事件块按声明顺序注册；显式 ``订阅事件`` 与自动订阅不重复。
7. **临时变量类型**\ ：``<=>``\ 的临时变量类型必须能容纳两侧值；对象下标交换已分别写回两侧。
8. **命名稳定**\ ：``@输出名``/命名方案改变名称但不改变绑定关系。
9. **null/原始类型**\ ：``空``\ 到原始类型按零值；其他 null 拆箱按 Java NPE。
10. **异常传播**\ ：不插入吞异常/改异常的包装，除非 ``code``\ 显式为之。

与目标语言不一致的地方
--------------------------------------------------------------------------------

以下条目已在 :doc:`../appendix/divergences` 展开；阅读语义时不要假设它们等价：

- 多表达式在非调用/非 ``=`` 构造位置仍按逗号表达式输出，Java 不接受。
- ``--dump-ast``\ 只输出摘要，不是完整 AST 转储。
- 输出目录不自动清理旧文件。
- 同时加载两套简单名相同 ``集合`` 的标准库会产生歧义。
- ``@禁用指针``\ 目前只记录 fact，不改变产物。
