.. _desugaring:

核心语义与语法糖
================

本节回答两个问题：

1. 哪些源语言结构是 **核心语义**\ ，必须由目标语言直接表达？
2. 哪些是 **语法糖**\ ，会被改写为核心结构？改写发生在什么阶段？

先说结论：本编译器 **没有独立的 lowered IR**\ ，也没有“翻译前统一脱糖”的 pass。parser 只做少量归一化；绝大多数语法糖在 Java 发射期由 emitter 直接改写为 Java 文本。因此“脱糖”在这里是“发射期降级”的同义词。

分类
--------------------------------------------------------------------------------

.. list-table:: 四类构造
   :header-rows: 1
   :widths: 16 84
   :name: table-desugar-classes

   * - 分类
     - 定义与例子
   * - 核心语义
     - 直接用目标 Java 结构表达、不可再去除的语义：类/方法/字段、控制流、表达式、类型、``创建``\ 、显式转换、``属于``\ 、``code``\ 。
   * - 语法糖
     - 可改写为更小核心结构的源语法：属性访问、事件、运算符重载、默认参数、``<=>``\ 、三种循环、单行方法、``=``\ 构造、隐式 cast、泛型特化、异步、顶级语句、自动创建、常量内联。
   * - 宿主逃逸
     - 语言语义不覆盖其内部：``code``/ ``@code``\ 、``#...``\ 文本替换、``@指代类``\ 外部类型、平台注解。
   * - 目标扩展
     - 由平台/语言目标注册表提供：Android 资源/清单/Gradle、JVM 控制台/调试、目标 requirements。

脱糖时机
--------------------------------------------------------------------------------

.. list-table:: 脱糖发生的位置
   :header-rows: 1
   :widths: 14 30 56
   :name: table-desugar-timing

   * - 时机
     - 代表构造
     - 说明
   * - 解析期
     - 顶层语句合成类、``[]``/``[]=``\ 方法名规范化、else 链嵌套、类型字符串拼接
     - parser 直接改变 AST 形状或保存原始文本；不做语义改写。
   * - 分析期
     - ``@编译条件``\ 裁剪、注解 facts/effects、平台 requirements、输出计划
     - 决定“输出什么”，不改变表达式/语句的语法结构。
   * - 发射期
     - 属性、事件、运算符重载、默认参数、循环、``<=>``\ 、泛型特化、异步、自动创建、code 引用
     - ``JavaEmitter``\ 在拼 Java 文本时完成降级；这是绝大多数语法糖的实际脱糖点。

核心语义
--------------------------------------------------------------------------------

以下构造直接映射为 Java，不需要糖改写：

.. list-table:: 核心语义
   :header-rows: 1
   :widths: 24 34 42
   :name: table-core-semantics

   * - 源结构
     - Java 形态
     - 备注
   * - ``包名 a.b``
     - ``package a.b;``
     - 可省略；输出包可能被 ``@输出名``\ 改写。
   * - ``类 X : Y``
     - ``public class X extends Y``
     - 单继承；无接口/枚举。
   * - ``变量/常量``
     - 字段/局部变量；``常量``\ 加 ``final``
     - 字段有默认值策略；局部没有。
   * - ``方法``
     - 方法声明；``= expr``\ 生成 ``return expr;``
     - 默认参数在调用点补。
   * - ``如果/否则``
     - ``if/else``
     - 常量条件会折叠并警告。
   * - ``假如``
     - ``switch``
     - emitter 插入 ``break``\ 。
   * - ``循环(cond)``
     - ``while (cond)``
     - 直接映射。
   * - ``返回``
     - ``return``
     - 带值/不带值。
   * - ``退出循环/跳过循环``
     - ``break``/ ``continue``
     - 循环外使用会报错。
   * - 字面量/标识符/字段访问/调用
     - 对应 Java 表达式
     - 名称会按命名方案重写。
   * - ``创建 T``/ ``创建 T()``
     - ``new T()``
     - 不支持构造参数。
   * - ``expr : T``
     - ``(T) expr``
     - 显式转换。
   * - ``expr 属于 T``
     - ``expr instanceof T``
     - 原始类型会报错，不生成非法 Java。
   * - ``code ...``/ ``@code...@end``
     - 原样 Java 文本（经 ``#``\ 替换/缩进归一）
     - 宿主逃逸，不做语法检查。

语法糖主表
--------------------------------------------------------------------------------

.. list-table:: 语法糖与目标 Java 形态
   :header-rows: 1
   :widths: 18 12 10 34 26
   :name: table-sugar-master

   * - 源结构
     - 分类
     - 时机
     - 目标 Java 形态
     - 必须保持/当前限制
   * - ``obj.prop``\ 属性读
     - 糖
     - 发射
     - ``obj.prop()``\ ；外部别名 ``Owner.prop(obj)``
     - 接收者只求值一次；裸 ``prop``\ 不重写。
   * - ``obj.prop = v``\ 属性写
     - 糖
     - 发射
     - ``obj.prop(v)``\ ；外部别名 ``Owner.prop(obj, v)``
     - 字段与属性同名时属性优先。
   * - ``定义事件``
     - 糖
     - 发射
     - 监听器接口 + 字段 + dispatch + setter
     - 无监听器时返回默认值。
   * - ``事件 obj:name(...)``
     - 糖
     - 发射
     - 匿名监听器 + ``set...Listener``
     - 自动/显式订阅；同一方法内重复订阅去重。
   * - ``订阅事件``
     - 糖
     - 发射
     - 发射类内全部事件块
     - 目标表达式被忽略。
   * - ``a + b``\ 用户类型
     - 糖
     - 发射
     - ``a.operator_plus(b)``
     - 普通类调用实例方法；``@指代类``\ 外部类调用静态跳板。
   * - ``a[i]``/ ``a[i] = v``
     - 糖/核心
     - 发射
     - Java 数组访问，或 ``operator_array_access``/ ``operator_array_assign``
     - 数组与用户下标器两条路径。
   * - ``a <=> b``
     - 糖
     - 发射
     - 临时变量交换
     - 仅语句位置；对象下标两侧读取后分别写回。
   * - ``循环(i, begin, end, step)``
     - 糖
     - 发射
     - ``for (int t = begin; t < end; t += step)``
     - 结束值独占；正/负步长都可生成。
   * - ``循环(coll -> x)``
     - 糖
     - 发射
     - ``for (E x : coll)``
     - 增强 for；map 双变量使用 ``entrySet``。
   * - ``循环(cond)``
     - 核心
     - 发射
     - ``while (cond)``
     - 直接映射。
   * - ``否则 <条件>``
     - 糖
     - 解析/发射
     - 嵌套 ``if``\ （``} else { if ... }``\ ）
     - 不承诺扁平化为 ``else if``\ 。
   * - 默认参数
     - 糖
     - 发射
     - 调用点补默认表达式
     - 无重载生成；空洞补 ``null``\ 。
   * - ``@隐式操作("cast")``
     - 糖
     - 发射
     - ``value.method()``
     - 只在转换上下文插入。
   * - ``=``\ 运算符
     - 糖
     - 发射
     - ``Target.operator_assign(value)``
     - 必须静态、返回当前类。
   * - 用户泛型 ``X<T>``
     - 糖
     - 发射
     - 空壳 ``X.java`` + ``X$Arg.java``
     - 外部泛型不生成壳。
   * - ``@异步方法`` + ``等待``
     - 糖
     - 发射
     - 上下文类 + ``_异步(int, Ctx)``\ 状态机
     - 条件中的 await 不支持。
   * - 顶级语句
     - 糖
     - 解析
     - 文件名 stem 合成类 + ``顶级语句``\ 方法
     - 需 ``--enable-toplevel-stmt``\ 。
   * - 自动创建
     - 糖
     - 发射
     - 字段/局部初始化器
     - 字段与局部规则不同。
   * - 常量内联
     - 糖
     - 发射
     - 仅无副作用字面量表达式在同类使用处展开
     - 其他常量使用字段引用，避免重复求值。

逐项说明
--------------------------------------------------------------------------------

.. _sugar-foreach:

遍历循环
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

源：

.. code-block:: text

   循环(数组 -> 项)
       调试输出(项)
   结束 循环

目标：

.. code-block:: java

   for (String rn_1 : 数组) {
     调试输出(rn_1);
   }

规则：

- 元素类型 ``E``\ 从集合的 **声明静态类型**\ 推导：
  - 数组 ``T[]`` → ``T``\ ；
  - 泛型 ``C<A, ...>`` → 第一个实参 ``A``\ ；
  - 其他 → ``Object``\ 。
- 使用 Java 增强 ``for``\ ，不生成索引循环，也不调用 ``取遍历器()``\ 。
- 对 ``Iterable``\ ，增强 ``for``\ 使用迭代器协议，保持惰性遍历与 fail-fast；对数组，``javac``\ 会生成索引遍历，但源语言层不暴露索引变量。
- 集合表达式只求值一次。
- 第二个循环变量（``循环(map -> 键, 值)``\ ）发射为 ``Map.Entry<K,V>`` + ``entrySet()``，键/值通过 ``getKey()``/``getValue()`` 绑定。

计次循环
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

源：

.. code-block:: text

   循环(i, 0, 10, 2)
       调试输出(i)
   结束 循环

目标：

.. code-block:: java

   for (int rn_1 = 0; rn_1 < 10; rn_1 += 2) {
     调试输出(rn_1);
   }

规则：

- 结束值独占；``0..9``\ 。
- 缺省：``begin = 0``\ 、``end = 0``\ 、``step = 1``\ 。
- ``begin``\ 在循环头只求值一次；``end``\ 与 ``step``\ 每轮求值。
- 步长可以为任意表达式；常量负步长使用 ``>`` 条件，动态步长生成一次方向判断，支持倒序循环。
- 循环变量被重命名为生成名；用户变量在循环体内通过 ``renames_``\ 替换。

条件循环
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``循环(cond) body 结束 循环``\ 直接映射为 ``while (cond) { body }``\ 。

如果/否则
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 直接映射 ``if/else``\ 。
- 常量布尔条件会被折叠：真则只发 then 分支，假则只发 else 分支，并报 ``code.constant-if``\ 警告。
- ``否则 <条件>``\ 作为嵌套 ``if``\ 发射；emitter 输出 ``} else { if (...) { ... } }``\ ，不保证写成 ``else if``\ 。
- ``否则 如果``\ 与 ``否则 <条件>`` 都只需一个 ``结束 如果``；见 :ref:`grammar-else-if`。

假如
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 映射为 Java ``switch``\ 。
- 每个 ``是``\ 可带多个值，emitter 为每个值发一个 ``case``\ 标签。
- 每个 case 末尾自动插入 ``break``\ ，没有 fallthrough。
- ``否则``\ 映射为 ``default``\ 。
- case 值必须是 Java 允许的编译期常量；字符串 switch 依赖 Java 7+。

.. _sugar-exchange:

交换 ``<=>``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

普通左值：

.. code-block:: text

   a <=> b

目标：

.. code-block:: java

   int rn_1 = b;
   b = a;
   a = rn_1;

规则：

- 只在 **语句位置**\ 特殊处理；表达式位置的 ``<=>``\ 没有对应的发射分支。
- 临时变量类型由左值静态类型推导。
- 普通左值交换的求值次数与源语义一致（每个左值读一次、写一次）。

对象下标交换会先读取两侧值到临时变量，再分别写回两侧下标；左右值格式不同仍由 lint 拒绝（报“交换式左右值格式不同”）。

.. _sugar-property:

属性
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

属性读/写声明：

.. code-block:: text

   属性读 名称(): 文本
       返回 字段
   结束 属性

   属性写 名称(值: 文本)
       字段 = 值
   结束 属性

也可写成 ``@属性读``/``@属性写`` 标注普通 ``方法``；parser 在成员解析阶段把方法种类转换为属性读/写，后续按同一套规则降级。

访问降级：

- ``obj.名称`` → ``obj.名称()``\ ；
- ``obj.名称 = v`` → ``obj.名称(v)``\ ；
- 外部 ``@指代类``\ 别名 → ``Owner.名称(obj)``/ ``Owner.名称(obj, v)``\ ；
- pinyin 命名模式下属性读/写分别输出 ``getX``/``setX``\ ；
- 字段访问解析时属性读优先于同名字段；
- **裸标识符** ``名称``\ 不会自动改写为 ``名称()``\ ；只有 ``obj.名称``\ 这种字段访问路径会查属性。
- ``#get<名称>``/ ``#set<名称>``\ 可在 ``code``\ 中强制选择属性方法。

.. _sugar-events:

事件
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``定义事件``\ ：

.. code-block:: text

   定义事件 完成(结果: 文本)

目标（简化）：

.. code-block:: java

   public void 完成(String 结果) {
     if (完成_v != null) {
       return 完成_v.dispatch(结果);
     }
     return null;
   }

   public interface 完成Listener {
     String dispatch(String 结果);
   }

   private 完成Listener 完成_v;

   public void set完成Listener(完成Listener receiver) {
     this.完成_v = receiver;
   }

规则：

- 事件定义生成监听器接口、私有字段、分发方法、setter。
- 无监听器时的默认返回：``boolean=false``\ 、``int=0``\ 、``long=0L``\ 、``float=0.0F``\ 、``double=0.0``\ 、其他引用 ``null``\ 。
- ``字符``/``字节``/``短整数`` 使用零值默认返回。
- 事件块 ``事件 obj:name(...) ... 结束 事件``\ 生成匿名监听器并调用 ``obj.set<Event>Listener(...)``\ ；处理器方法名为 ``obj$name``\ 。
- 自动订阅：组件类在 ``创建完毕``\ 方法末尾（或显式 ``订阅事件``\ 处）发射类内所有事件块。
- ``订阅事件`` 的目标表达式被忽略；它总是发射类内全部事件块。同一方法内重复 ``订阅事件`` 会去重。
- ``@属性需求``\ 会在订阅后追加 ``receiver.property(true)``\ 。

分派规则：

- 二元运算：若左操作数静态类型可解析，在类型链中查找同名方法；找到则分派。普通类发射 ``left.operator_xxx(right)``\ ；``@指代类``\ 外部类发射静态跳板 ``Owner.operator_xxx(left, right)``\ 。
- 下标读：接收者不是数组且声明了 ``[]`` → ``receiver.operator_array_access(index)``\ 。
- 下标写：声明了 ``[]=`` → ``receiver.operator_array_assign(index, value)``\ 。
- ``=``\ 运算符：静态构造/转换，发射 ``Type.operator_assign(value)``\ 。
- ``<=>``\ ：普通左值走临时变量交换；``operator_swap``\ 名称存在但 emitter 不调用。
- 外部类型示例：``文本 == "a"`` → ``文本.operator_equal(文本变量, "a")``\ ；``文本 ? "b"`` → ``文本.operator_question(文本变量, "b")``\ 。

默认参数
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

源：

.. code-block:: text

   方法 输出(前缀: 文本 = ">", 内容: 文本 = "")
   结束 方法

   输出(, "x")

目标：

.. code-block:: java

   输出(">", "x");

规则：

- 默认参数在 **调用点**\ 展开；不生成重载。
- 省略的尾部参数使用默认表达式；显式空洞 ``(, x)``\ 也使用默认值。
- 没有默认值且实参缺失时补 ``null``\ ；lint 会检查实参数量。
- 默认表达式在声明点的上下文中发射。

转换
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

隐式 cast 与 ``=``\ 运算符的降级规则见 :ref:`types`：

- ``@隐式操作("cast")`` → ``value.method()``\ ；
- ``=``\ 运算符 → ``Target.operator_assign(value)``\ ；
- 空值 → 原始类型零值/引用 ``null``\ ；
- 数组字面量 → ``new T[]{...}``\ 。

.. _sugar-generics:

泛型
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 用户泛型类 ``盒子<T>``\ ：生成空壳 ``盒子.java``\ 与按实参的特化 ``盒子$整数.java``\ 。
- 外部泛型 ``集合<文本>``\ ：不生成文件，保留 Java 泛型 ``java.util.ArrayList<String>``\ 。
- 数组实参 ``T[]``\ ：编码为 ``$Array``\ 。
- 嵌套实参：递归 ``$``\ 。
- 外部类的成员发射为静态跳板，首参 ``__this_obj``\ ；**所有** ``@指代类``\ 外部类都这样，不只泛型。
- 上限 500 轮；超过后停止扩展，可能留下未生成的特化。

.. _sugar-async:

异步
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``@异步方法`` + ``等待``\ 的降级：

- 生成上下文类 ``<类>_<方法>_异步上下文``\ ，把参数、局部变量、等待临时值、循环计数器与步长、foreach 迭代器/元素提升为 ``public``\ 字段。
- 生成状态机方法 ``<方法>_异步(int 状态, 上下文 上下文)``\ ，用 ``switch (状态)``\ 分派。
- 生成包装方法 ``<方法>(参数...)``\ ：创建上下文、复制参数、调用入口状态。
- 线程转换：
  - 等待前状态在全局调度器；
  - 等待后状态在主线程；
  - ``@异步方法(独立线程=真)``\ 使用独立单线程调度器。
- 状态编号从入口 BFS，循环的 exit/body 有优先展开；未被引用的状态丢弃。
- foreach 降级为迭代器状态机：初始化状态调用 ``.iterator()``\ ，条件状态调用 ``hasNext()``/``next()``\ ，循环体结束回到条件状态；map 双变量通过 ``entrySet()``\ + ``getKey()``/``getValue()``\ 绑定。
- 支持：``如果``\ 、``假如``\ 、计次循环、while、foreach（含循环体内等待）、``退出循环``\ 、``跳过循环``\ 、``返回``\ 、局部变量、语句/变量初始化中的等待、``如果`` 条件中的等待、while 条件中的等待。
- 不支持：计次循环头部（begin/end/step）中的等待、foreach 集合表达式本身的等待、异步返回值。

顶级语句
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``--enable-toplevel-stmt``\ 时：

- 用文件名 stem 合成一个类；
- 顶层成员补 ``@强制输出``\ ；
- 顶层语句收集到方法 ``顶级语句``\ ；
- 合成类带 ``@全局类``\ 与 ``@强制输出``\ ；
- 未开启该选项时，顶层语句报 ``源文件中只允许类声明``\ 。

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

字段与局部变量都会补默认值；局部变量不使用组件/资源特例：

   :header-rows: 1
   :widths: 18 40 42
   :name: table-autoinit

   * - 位置/类型

     - 条件

   * - 字段：外部引用别名

.. _sugar-coderefs:

``#``\ 代码引用
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在 ``code``/``@code``\ 文本中，``#``\ 由 emitter 做文本替换：

.. list-table:: 代码引用
   :header-rows: 1
   :widths: 22 78
   :name: table-code-refs

   * - 形式
     - 含义
   * - ``#cls<T>``
     - 解析类型并输出输出类名；未解析保持原文。
   * - ``#ncls<T>``
     - 通过 ``MapType``\ 输出 Java 类型。
   * - ``#mem<Owner.member>``
     - 解析并输出重命名后的 ``Owner.member``\ ；无 ``.``\ 保持原文。
   * - ``#expr<text>``
     - 对 ``text``\ 中的标识符做局部/参数/成员重命名。
   * - ``#get<prop>``/ ``#set<prop>``
     - 强制选择属性读/写方法。
   * - ``#sys<main_pkg>``
     - 平台资源命名空间（若存在）。
   * - ``#sys<source>``/ ``#sys<line>``/ ``#sys<time>``
     - 源文件路径/当前代码行/当前毫秒数 + ``L``\ 。
   * - ``#this``
     - ``Class.this``\ ；静态别名上下文为 ``__this_obj``\ 。
   * - ``#name``
     - 参数/局部/成员的重命名；未找到保持 ``#name``\ 。

替换是引号感知的；普通表达式中的 ``#``\ 不是合法前缀。``#参数``\ 不是特殊语法，``参数``\ 只是普通参数名。
