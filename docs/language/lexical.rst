.. _lexical:

词法规范
========

本节定义结绳源文件的字符集、标识符、字面量、代码块、运算符与词法诊断。实现位于 ``src/frontend/lexer.cpp``\ ，Token 定义位于 ``src/frontend/token.h``\ 。

.. contents:: 目录
   :local:
   :depth: 2

源文件与编码
--------------------------------------------------------------------------------

- 源文件按 UTF-8 解码；文件开头的 UTF-8 BOM（``EF BB BF``\ ）会被跳过。
- 行号从 0 开始计数；``Unit::line_count = 1 + 换行符数量``\ 。
- 块结构由 ``结束 ...``\ 终止符决定，**不依赖缩进**\ 。缩进只用于 ``code``\ 块的反缩进计算。
- 列号从 0 开始；诊断输出时行、列都加 1。AST 中的 ``declaration_line``\ 、``end_line``\ 、``code_line``\ 等字段是 1 基。
- 制表符宽度 ``kTabWidth = 4``\ 用于列推进；但缩进级别 ``indent_level = tabs + spaces / 4``\ ，即 **一个 tab 计 1 级**\ ，不是 4 级。

字符与标识符
--------------------------------------------------------------------------------

.. code-block:: text

   identifier   = id_start { id_part } ;
   id_start     = ascii_letter | "_" | "$" | non_ascii_byte ;
   id_part      = id_start | ascii_digit ;
   ascii_letter = "A".."Z" | "a".."z" ;
   ascii_digit  = "0".."9" ;
   non_ascii_byte = ? 任意 UTF-8 多字节序列中的字节 >= 0x80 ? ;

规则：

- ASCII 字母、数字、``_``\ 、``$``\ 可作为标识符字符；ASCII 数字不能作为首字符。
- 任何非 ASCII 字节都视为标识符字节，因此中文、日文、emoji 等都可出现在标识符中。
- 全角标点范围 ``U+3000..U+303F``\ 与 ``U+FF00..U+FFEF``\ 不被接受；遇到时报 ``请使用半角符号: X``\ 并跳过该字符。
- 全角字母（如 ``Ａ``\ ）不属于上述标点范围，会作为非 ASCII 标识符字节接受。

**相邻中文词会合并。**\ 因为中文关键字只是普通标识符，``结束 类``\ 、``否则 如果``\ 、``变量 计数``\ 、``类 启动窗口``\ 之间必须有空白或标点；``结束类``\ 是一个完整标识符，不会被识别为 ``结束`` + ``类``\ 。

空白、换行与注释
--------------------------------------------------------------------------------

- 空白：空格、tab、CR、LF。
- 行注释：``//``\ 到行尾。
- 块注释：``/* ... */``\ ，**不嵌套**\ ；未闭合的块注释会一直消费到文件末尾，且 **不报错**\ 。
- 注释在词法阶段被跳过，不产生 Token；注释内容不会进入 AST。

上下文关键字
--------------------------------------------------------------------------------

结绳 **没有词法保留字**\ 。关键字都是 ``kIdentifier``\ ，由 parser 在声明/语句/表达式位置按上下文解释。因此关键字在普通表达式中可作为标识符使用，但在关键字位置不能作为普通名字。

     - 语句
     - 触发类内事件块订阅。

     - 异步等待；仅异步方法有意义。
   * - ``属于``
     - 表达式

   * - ``或``/ ``且``
     - 表达式

   * - ``为``
     - 成员/参数声明
     - 类型分隔符的另一种写法；局部变量只接受 ``:``\ 。
   * - ``空``/ ``真``/ ``假``
     - 表达式
     - 空引用、布尔字面量。
   * - ``本对象``/ ``父对象``
     - 表达式
     - 当前对象/父类对象。
   * - ``code``
     - 成员/语句/初始化
     - 单行嵌入代码块。
   * - ``@code``/ ``@end``
     - 词法
     - 多行嵌入代码块及其终止符；``@code``\ 不是注解。

不在语言中的词：

- ``遍历``\ ：不存在；遍历循环写作 ``循环(集合 -> 项)``\ 。
- ``继承``\ ：parser 不消费；继承只写 ``类 子类 : 父类``\ 。
- ``非``\ 、``已定义``\ 、``未定义``\ ：只出现在 ``@编译条件``\ 的子语言中，不是表达式运算符/函数。
- ``或者``\ ：``@编译条件``\ 中视为非法；逻辑或写作 ``或``\ 或 ``||``\ 。
- ``参数``\ ：普通标识符；注解的默认位置参数名为 ``参数``\ ，但它不是特殊语法。

字面量
--------------------------------------------------------------------------------

数字
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

数字 Token 的识别顺序：先判断十六进制，再读取十进制整数部分、可选小数部分、可选指数，最后检查后缀。

.. list-table:: 数字字面量
   :header-rows: 1
   :widths: 22 18 60
   :name: table-numeric-literals

   * - 写法
     - Token 种类
     - 说明
   * - ``123``
     - ``kInteger``
     - 十进制整数。
   * - ``0x1F``/ ``0XFF``
     - ``kInteger``
     - 十六进制整数；至少 ``0x``\ 即被接受。
   * - ``077``
     - ``kInteger``
     - 八进制整数；Token 文本归一为十进制（``077`` → ``63``）。
   * - ``123L``/ ``123l``
     - ``kLong``
     - 长整数后缀。
   * - ``123F``/ ``123f``
     - ``kFloat``
     - 单精度后缀。
   * - ``123D``/ ``123d``
     - ``kDouble``
     - 双精度后缀。
   * - ``1.5``\ 、``1e3``\ 、``1E-3``
     - ``kDouble``
     - 小数点或指数使其成为小数。
   * - ``1.5F``
     - ``kFloat``
     - 小数 + 单精度后缀。
   * - ``1.5L``
     - 错误
     - **词法错误**\ ：小数不能带 ``L`` 后缀，报 ``此处不应该出现 'L'``\ 。
   * - ``0xFFL``
     - ``kLong``
     - 十六进制长整数；``L/l`` 后缀被接受。
   * - ``1.``
     - ``kInteger`` + ``.``
     - 小数点后必须紧跟数字才被消费。
   * - ``1e``
     - ``kDouble``
     - 指数部分不要求有数字，仍按小数 Token 接受。

不支持的写法：二进制、数字分隔符、无符号后缀、``NaN``/``Infinity``\ 字面量、带符号的数字字面量（符号是一元运算符）。

字符
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

字符字面量写作 ``'...'``\ ：

- 内容为一个 Unicode 标量（可以是非 ASCII 字符）或一个转义。
- 识别转义：``\n``\ 、``\t``\ 、``\r``\ 、``\0``\ 、``\\``\ 、``\'``\ 。
- ``\b``\ 、``\f``\ 、``\u``\ 在字符字面量中 **不特殊**\ ：默认行为是去掉反斜杠并保留后面的字符。
- 多于一个字符、缺少结束引号：报 ``未结束的字符字面量或包含多个字符``\ 。
- ``raw``\ 保留引号，``text``\ 是解码后的内容。

字符串
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

字符串字面量写作 ``"..."``\ ：

- 识别转义：``\n``\ 、``\t``\ 、``\r``\ 、``\b``\ 、``\f``\ 、``\0``\ 、``\\``\ 、``\"``\ 、``\'``\ 。
- ``\u`` **不解析**\ ：会原样保留为 ``\`` + ``u``\ 两个字符，因此 ``"\u4e2d"``\ 的 ``text``\ 仍是 ``\u4e2d``\ 。
- 其他未知转义：去掉反斜杠，保留被转义的字符。
- 字符串内允许直接换行。
- 文件结束前没有闭合引号：报 ``未结束的字符串``\ 。
- ``raw``\ 包含引号，``text``\ 是解码后的内容；Java 发射器会基于 ``raw``\ 重新转义。

长字符串
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

长字符串写作 ``[[ ... ]]``\ ：

- ``text``\ 是两个方括号之间的原始内容；``raw``\ 包含 ``[[``\ 与 ``]]``\ 。
- 不做任何转义处理，可以跨行，在第一个 ``]]``\ 处结束。
- 未闭合时消费到文件末尾，**不报错**\ 。
- 主要用于注解参数、清单片段等元数据载荷。Java 发射器只把以 ``"``\ 或 ``'``\ 开头的原始文本当作带引号的 Java 字符串；``[[...]]``\ 不应作为普通 ``文本``\ 表达式使用。

布尔、空与特殊对象
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``真``\ 、``假``\ 、``空``\ 、``本对象``\ 、``父对象``\ 在词法上都是普通标识符。parser 在表达式 primary 位置把它们映射为：

- ``真``/ ``假`` → 字面量表达式，文本分别为 ``真``/ ``假``\ ；
- ``空`` → ``kNull``\ ；
- ``本对象`` → ``kThis``\ ；
- ``父对象`` → ``kSuper``\ 。

因此它们不是保留字；在字段名等位置使用它们是否合法取决于上下文。

代码块
--------------------------------------------------------------------------------

单行 ``code``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

识别条件（``Lexer::Lex``\ ）：

- 当前标识符以 ``code``\ 开头且恰好是 ``code``\ ；
- 后面紧跟 EOF、空格、tab、CR 或 LF；
- 且不是 ``code(``\ 。

满足条件时，整个 ``code``\ 到行尾的文本成为一个 ``kCodeBlock`` Token：

- ``raw = "code"``\ ；
- ``text``\ 是去掉行尾 CR、去掉首尾空格/tab 后的剩余文本；
- ``indent_level``\ 是该 Token 的缩进级别。

**不要求行首。**\ 只要出现 ``code``\ 且后面是空白/行尾，就会成为代码块。因此 ``obj.code``\ 在行尾、``obj.code ``\ 后跟空白时会被误识别为代码块，而不是字段访问。``code()``\ 仍是普通方法调用，``code;``/ ``codex``\ 仍是普通标识符。

多行 ``@code``/ ``@end``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

识别条件：``@code``\ 后紧跟 EOF、空格、tab、CR、LF 或 ``(``\ 。``Lexer::LexCodeBlock``\ 的行为：

1. 跳过 ``@code``\ ；
2. 如果紧跟 ``(``\ ，扫描到 **第一个** ``)``\ 并跳过（可以跨行）；头部内容被丢弃；
3. 跳到下一行；正文从下一行开始；
4. 从正文起点逐字符扫描：在每个扫描位置先跳过空格/tab，如果接下来是 ``@end``\ 且其后是 EOF/换行/空格/tab/CR，则终止；否则继续前进一个字符；
5. 终止时跳过 ``@end``\ 所在行的剩余内容；未找到则报 ``未闭合的 code 块（缺少 @end）``\ ，正文消费到 EOF。

要点：

- ``@end`` **不是严格行首**\ ：只要在某个位置跳过空格/tab 后遇到 ``@end``\ 即可终止，因此 ``foo @end``\ 也可能提前结束代码块。
- 扫描不识别字符串、注释或嵌套；Java 字符串中出现 ``@end``\ 也会终止。
- 代码块不可嵌套；``@code``\ 头部可以写标记，但内容被丢弃。
- ``raw``\ 与 ``text``\ 都是正文原文；``indent_level``\ 是 ``@code``\ 起始处的缩进。
- ``@end``\ 不是注解，也不会进入 AST。

运算符与分隔符
--------------------------------------------------------------------------------

``Lexer::LexSymbol``\ 使用最长匹配，符号表为：

.. code-block:: text

   <=>   ...   ->   ==   !=   <=   >=   &&   ||
   @     #
   +  -  *  /  %  &  |  ^  <  >  =  ?  :  .  ,  ;  (  )  {  }  [  ]

说明：

- ``...``\ 是方法声明中“无方法体”的标记（如 ``方法 f(...) = ...``\ ）。
- ``#``\ 在普通表达式中不是合法前缀；代码引用（``#cls``\ 、``#mem``\ 等）是在发射期对 ``code``\ 文本做的文本替换，不是词法/语法构造。
- 没有一元 ``!``\ 、``~``\ 、``++``\ 、``--``\ 、复合赋值（``+=``\ 等）、移位（``<<``/``>>``\ ）、``::``\ 、``=>``\ 、``??``\ 、三元 ``?:``\ 。
- ``?``\ 有两种用途：表达式中的二元运算符（比较级，可由用户类型重载）和类型声明末尾的可空后缀。
- ``:``\ 是类型分隔符、类型转换运算符和事件对象/事件名分隔符；它 **不是**\ 三元运算符的一部分。

Token 模型与位置
--------------------------------------------------------------------------------

.. list-table:: TokenKind
   :header-rows: 1
   :widths: 24 76
   :name: table-token-kinds

   * - 种类
     - 含义
   * - ``kEnd``
     - 文件结束。
   * - ``kIdentifier``
     - 标识符/上下文关键字。
   * - ``kInteger``
     - 十进制或十六进制整数。
   * - ``kLong``
     - 长整数后缀 Token。
   * - ``kFloat``
     - 单精度小数后缀 Token。
   * - ``kDouble``
     - 双精度小数 Token。
   * - ``kChar``
     - 字符字面量。
   * - ``kString``
     - 字符串字面量。
   * - ``kLongString``
     - ``[[...]]``\ 长字符串。
   * - ``kCodeBlock``
     - 单行 ``code``\ 或多行 ``@code``\ 块。
   * - ``kSymbol``
     - 运算符/分隔符。

``Token``\ 字段：

.. code-block:: cpp

   struct Token {
     TokenKind kind = TokenKind::kEnd;
     std::string text;   // 解码后的值；字符串/字符为内容，其余为词素
     std::string raw;    // 原始词素；字符串/字符包含引号
     SourcePosition position;  // line/column/offset，均 0 基
     bool begins_line = false; // 仅当 column == 0
     int indent_level = 0;     // tabs + spaces / 4
   };

注意：

- ``begins_line``\ 只在列 0 为真；缩进的行不会标记为行首。parser 的错误同步逻辑依赖它，因此缩进行的同步可能一直跳到 EOF。
- ``kCodeBlock``\ 的 ``raw``/``text``\ 对单行 ``code``\ 与多行 ``@code``\ 含义不同：单行时 ``raw = "code"``\ 、``text``\ 是剩余内容；多行时两者都是正文。
- 字符串/字符的 ``text``\ 已解码，``raw``\ 保留引号；数字的 ``text``\ 与 ``raw``\ 相同。

词法诊断与恢复
--------------------------------------------------------------------------------

.. list-table:: 词法诊断
   :header-rows: 1
   :widths: 30 18 52
   :name: table-lex-diagnostics

   * - 消息
     - 触发条件
     - 恢复
   * - ``请使用半角符号: X``
     - 遇到全角标点 ``U+3000..U+303F``/ ``U+FF00..U+FFEF``
     - 跳过该字符并继续。
   * - ``未结束的字符串``
     - 字符串缺少结束引号
     - Token 消费到 EOF。
   * - ``未结束的字符字面量或包含多个字符``
     - 字符字面量缺少结束引号或多于一个字符
     - Token 消费到 EOF 或结束引号。
   * - ``此处不应该出现 'L'``
     - 小数（含小数点/指数）带 ``L``\ 后缀
     - 诊断后仍产生 ``kLong``\ Token，编译失败。
   * - ``未闭合的 code 块（缺少 @end）``
     - ``@code``\ 没有 ``@end``
     - 正文消费到 EOF，仍产生 Token。
   * - ``无法识别的字符: X``
     - 不在符号表中的单字节字符
     - 产生一个单字符 ``kSymbol`` Token 并继续。

未闭合的 ``/* ... */``\ 与未闭合的 ``[[...]]`` **不产生诊断**\ ，这是已知的静默行为。

已知词法陷阱
--------------------------------------------------------------------------------

.. list-table:: 词法陷阱速查
   :header-rows: 1
   :widths: 30 70
   :name: table-lex-pitfalls

   * - 陷阱
     - 说明
   * - 中文词粘连
     - ``结束类``\ 、``变量计数``\ 、``否则如果``\ 都是单个标识符；必须写空格。
   * - ``code``\ 不限行首
     - ``obj.code``\ 在行尾会被当作代码块；需要访问字段时避免让 ``code``\ 成为行尾词。
   * - ``@end``\ 不限行首
     - 行中 ``@end``\ 也可能提前结束代码块；不要在 Java 字符串中写 ``@end``\ 。
   * - 长字符串不是普通字符串
     - ``[[...]]``\ 不做转义、不是 Java 字符串表达式；主要用于元数据/清单片段。
   * - ``1.5L``/ ``0xFFL``
     - ``1.5L`` 被词法拒绝；``0xFFL`` 是合法长整数。
   * - 全角标点
     - 中文逗号、括号、分号会报错；必须使用半角。
   * - tab 缩进
     - 一个 tab 只计 1 级缩进；混合 tab/空格时 ``code``\ 块反缩进可能不符预期。
   * - 未闭合注释/长字符串
     - 不报错，可能静默吞掉后续源码。
